# TenderTrace 全国与全球机会雷达及数据源可信度地图优化进度与验收报告

**报告日期：** 2026年9月28日  
**独立验收对象：** 提升方向十——全国机会雷达与数据源可信度地图  
**产品界面名称：** 全国与全球机会雷达  
**验收结论：** 通过；已达到本地索引可视化、全球与全国切换、来源状态透明、离线可回放、可进入真实项目且适合投屏展示的要求

## 一、验收结论摘要

全国与全球机会雷达已经作为独立模块接入 TenderTrace 主导航。地图不依赖在线地图服务，不生成随机闪烁点，而是直接聚合本地机会索引与已保存的数据源健康记录。用户可以在全球总览、全国机会和国际机会之间切换，按时间窗口和采购品类筛选，点击地图光点查看对应机会，并继续进入项目数字档案或把地区条件带入自然语言查询。

本次独立验收的核心结果如下：

- 全球地图与全国地图采用内置 SVG，不依赖现场网络或第三方地图资源。
- 当前非演示本地索引包含45条机会，其中国内33条、国际12条。
- 地图展示18个有真实机会的地区节点，节点数量与结果列表严格一致。
- 全球视图覆盖中国、欧洲、非洲、东南亚、北美和拉丁美洲等区域。
- 全国视图按省级或全国节点展示机会数量、近7天新增、热门品类和平均来源可信度。
- 点击地图节点可以查看真实机会列表，点击机会可以进入原有项目数字档案。
- 地区条件可以一键带入现有自然语言工作台，继续运行真实检索。
- 数据源可信度地图覆盖16个国内外来源，显示运行状态、成功率、延迟、最近成功、最近异常、访问限制和本地结果数。
- “来源故障”和“本地0条结果”使用两个独立字段和视觉状态表达。
- 当前来源状态为14个正常、2个需关注、6个本地零结果；零结果不自动判定为故障。
- 手动刷新只重新计算本地索引并保存快照，不会在展示现场触发外部网络采集。
- 页面支持关闭动效和大屏模式，关闭动效后所有信息仍然完整可读。
- 全项目回归通过：513项测试、564项子测试全部通过，0项失败。

## 二、原问题与解决目标

项目此前已经拥有数据源列表、机会台账和来源健康指标，但它们分布在不同页面。使用者需要逐项查看才能回答“机会集中在哪里”“哪些品类正在增加”“国际机会来自哪些地区”“当前来源能不能信”“没有结果是网站故障还是确实没有采到”等问题。评委也难以在短时间内直观看到系统的覆盖范围和数据诚实性。

本次优化解决以下问题：

1. 用一张地图展示全国和全球机会分布，而不是只展示表格。
2. 地图上的每个点都必须能回到本地真实记录。
3. 数据源可信状态必须与结果数量分开，防止把故障误解为零机会。
4. 有限本地算力下仍能稳定展示，并支持人员手动更新快照。
5. 断网或外部网站不可用时，仍能使用最近一次本地索引完成主路径。
6. 展示模式需要适合大屏，同时保留普通用户的筛选和下钻操作。

## 三、产品流程与展示设计

### 3.1 独立导航入口

主导航新增“机会雷达”。该入口与工作台、机会情报、数据源、组织协作并列，不覆盖原有页面。用户进入后首先看到本地索引截至时间、机会数、近7天新增、来源数、需关注来源和最近快照状态。

产品页面没有出现“方向十”等内部研发编号。

### 3.2 三种地图范围

页面提供三种范围：

- **全球总览：** 同时展示国内和国际机会，适合比赛开场说明覆盖范围。
- **全国机会：** 使用中国区域底图，聚焦省级机会密度与热门品类。
- **国际机会：** 只展示国际索引，突出欧洲、非洲、亚洲、美洲等区域。

切换范围时，机会数、地区数、品类热度、最近新增和来源列表同步重新计算。

### 3.3 机会雷达地图

地图节点使用以下视觉编码：

- 圆点大小表示当前地区的本地索引机会数量。
- 绿色表示该地区对应来源平均可信度较高。
- 黄色表示需要关注。
- 红色表示来源证据不足或当前状态待验证。
- 节点旁显示地区名称和机会数量。

地图背景、经纬网格、扫描圈和节点全部使用本地 SVG 与 CSS。动画只是视觉辅助，不影响业务数据。关闭动效后地图、数字和操作入口全部保留。

### 3.4 地区下钻

点击地图节点后，右侧检查器展示：

- 地区名称
- 本地机会总数
- 近7天新增
- 来源平均可信度
- 热门品类
- 当前地区的真实机会列表

点击机会直接调用原有项目档案接口。点击“带入自然语言查询”会把时间、地区和品类写入工作台输入框，用户可以检查意图后运行检索。

### 3.5 品类热度与最近新增

地图下方展示品类热度排名，包含数量、比例和热度条。点击品类后地图按该品类重新聚合。最近新增区展示标题、地区、品类、发布时间和来源，并提供项目档案入口。

### 3.6 数据源可信度地图

来源地图先在全球底图上显示16个来源的大致覆盖区域和当前状态，再以卡片形式逐一展示：

- 来源机构与内部站点编码
- 国内或国际范围
- 运行状态
- 请求成功率
- 平均延迟
- 本地索引结果数
- 最近成功时间
- 最近异常
- 登录、许可或覆盖限制

来源可用状态和本地数据状态分别保存。例如，中国政府采购网当前可标记为异常，但本地仍保留可用历史记录；某来源也可以运行正常但当前本地结果为0条。系统不会把两类情况合并成一个模糊状态。

### 3.7 大屏与低算力模式

大屏模式隐藏顶部应用栏、扩展地图高度并放宽页面宽度。关闭动效按钮会停止扫描圈和节点脉冲。在操作系统开启减少动态效果时，页面也会自动关闭动画。地图本身不加载瓦片、WebGL或大型地图框架，适合当前本地计算环境。

## 四、已完成的技术措施

### 4.1 轻量聚合服务

新增 `opportunity_radar.py`，直接读取 `notices`、`source_observations`、运行记录和现有 `source_map`。服务提供范围、时间窗口和品类筛选，输出汇总指标、地区聚合、品类热度、来源状态、最近机会和完整机会列表。

服务明确返回：

- `index_mode=local_index`
- `network_fetch_performed=false`
- `random_points_forbidden=true`
- `zero_results_separate_from_faults=true`
- `manual_refresh_only=true`

### 4.2 地理映射

国内节点支持31个省级行政区域及港澳台显示位置，并处理省、市、自治区等常见写法。国际节点将国家、区域代码和机构覆盖范围映射到欧洲、非洲、北美、拉丁美洲、东南亚、南亚、中东、中亚与大洋洲等区域。

无法可靠判断的国际地区保留原始地区名称，并使用对应来源的覆盖锚点，不虚构精确经纬度。

### 4.3 品类识别

优先读取公告结构化字段中的采购品类；没有结构化品类时，复用现有主题词典从标题和正文识别服务器、充电桩、空调、医疗设备等品类。无法可靠归类时显示“其他”，不强行猜测。

### 4.4 来源可信状态

来源可信状态复用现有运行和观测记录，综合请求成功率、运行成功率、阻断比例与延迟。页面不重新发明第二套健康分数。最近失败晚于最近成功时，状态明确显示当前异常。

### 4.5 结果与故障分离

每个来源包含两个独立状态：

- `availability_status`：正常、性能下降、当前异常、尚未验证或访问受限。
- `data_status`：本地有结果或本地0条结果。

因此可以同时表达“网站当前异常，但本地有历史结果”以及“网站运行正常，但当前筛选没有结果”。

### 4.6 手动快照与离线回放

数据库模式升级到47，新增 `opportunity_radar_snapshots`。点击“刷新本地快照”时，系统重新读取本地索引和来源健康记录并保存当前范围、时间窗口、品类、机会数、来源数、完整载荷、操作者和时间。

快照刷新不触发外部网站访问。即使现场断网，页面仍可读取 SQLite 本地索引与已保存快照。

### 4.7 接口

新增两个接口：

1. `GET /api/opportunity-radar`：读取本地机会和来源状态，支持范围、时间窗口和品类参数。
2. `POST /api/opportunity-radar/refresh`：手动计算并保存当前快照。

无效范围会返回400，不会静默改成其他范围。

## 八、低算力与断网策略

当前实现没有把“实时”包装成持续联网的大数据流。页面每次打开时快速聚合本地SQLite索引；人员需要更新展示数据时，可以先运行现有采集任务，再点击“刷新本地快照”。

现场断网时的操作顺序：

1. 使用已保存的本地索引打开全球总览。
2. 展示数据截至时间和快照时间。
3. 切换全国、国际和品类筛选。
4. 点击地区与项目档案完成主路径。
5. 来源卡继续展示最近一次已保存的成功、异常和延迟记录。

系统不会在断网时把旧数据称作实时数据，也不会把外部访问失败改写成零机会。

## 十、比赛演示建议

建议采用以下3分钟流程：

1. 以全球总览开场，指出地图45条机会全部来自本地索引。
2. 展示国内33条、国际12条以及18个有数据地区。
3. 切换到全国机会，点击浙江或上海查看真实项目。
4. 打开一条机会进入数字档案，证明地图不是独立大屏。
5. 返回地图，点击服务器品类，展示品类筛选后的区域变化。
6. 打开来源可信度地图，解释16个来源状态。
7. 对比“当前异常但有历史结果”和“正常但0条结果”两张来源卡。
8. 点击关闭动效，再切换大屏模式，展示低算力和投屏适配。
9. 最后点击刷新本地快照，说明现场不会触发不可控外部采集。

评委追问“这是否真正实时”时，建议直接回答：当前版本是本地索引准实时态势图，由现有采集任务更新数据，页面按需重新聚合；比赛现场采用人工刷新快照，确保数据口径清楚、离线可用和演示稳定。

## 十一、风险边界与后续建议

当前实现已经满足本地项目与比赛展示需求，但仍保留以下诚实边界：

1. 国际地区使用国家或重点区域级映射，不宣称精确到城市经纬度。
2. 来源可信度反映最近运行证据，不代表来源内容永远正确。
3. 本地0条表示当前索引没有记录，不代表外部网站绝对没有项目。
4. 地图不是持续流式系统，外部采集频率仍由现有调度和人员控制。
5. 后续数据量明显增长后，可增加预聚合表和增量刷新，但当前45条有效索引的数据无需引入复杂基础设施。
6. 若继续扩展方向十七，可在当前地图上增加交易流向和外部事件图层，但必须与本方向的数据覆盖地图保持明确区分。

全国与全球机会雷达及数据源可信度地图已达到“用户能直观看见机会在哪里、什么品类正在增加、哪些来源当前可靠、为什么没有结果、地图能回到真实项目、断网仍能展示、低算力也能稳定投屏”的目标。

本方向功能、数据口径、快照机制、页面交互、本地运行和全项目回归均已通过。当前模块可以直接用于全国总决赛路演，也为后续增加更大规模的国际机会和外部事件图层保留了清晰接口。
