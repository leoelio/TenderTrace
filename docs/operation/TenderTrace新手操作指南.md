# TenderTrace 新手操作指南

适用环境：当前这台 Windows 电脑上的 `E:\tt` 项目。  
本指南只写日常最常用的操作，不需要懂代码。

## 一、这个项目能做什么

| 功能 | 通俗说明 |
|---|---|
| 招标信息查询 | 用一句话查询某个地区、时间和产品相关的招投标信息 |
| Word 报告 | 自动把查询结果整理成可下载的 Word 文件 |
| 机会情报 | 汇总值得跟进的项目，并显示评分、截止时间、负责人和风险 |
| 定时订阅 | 按每天 09:00 等时间自动查找新增公告，已经发过的内容不会重复发送 |
| 飞书项目群 | 把报告、项目卡片和提醒发送到 `TT 项目组群` |
| 飞书机器人 | 在群里向机器人 `123` 提问、记录组织记忆或提交项目意见 |
| 飞书任务 | 为需要跟进的项目创建任务并指定负责人 |
| 飞书日历 | 为投标截止日期创建日程提醒 |
| 飞书多维表格 | 把项目、负责人、任务状态和日程等信息同步到“招标机会”表 |
| 组织协作 | 保存团队共享信息，之后可以在网页或飞书群里查询 |
| 数据源检查 | 查看各招标网站是否正常、最近是否采集成功 |
| 历史记录 | 查看以前运行过的查询、报告和处理过程 |

## 二、怎样打开

### 正常打开

1. 双击 `E:\tt\scripts\start-local.cmd`。
2. 等待约 10 秒。
3. 用浏览器打开：<http://127.0.0.1:8000/>
4. 页面底部显示“系统状态：正常”，说明可以使用。

如果网页已经能打开，就不需要重复启动。

### 关闭

不再使用时，可以双击：

```text
E:\tt\scripts\stop-local.cmd
```

## 三、最常用的操作

### 1. 立即查询招标信息

1. 打开顶部的“工作台”。
2. 在“自然语言问题”中输入需求，例如：

   ```text
   最近1个月上海服务器招标信息都有哪些？
   ```

3. 选择“立即运行”。
4. 如果还想发到飞书，勾选“同时发送飞书”。
5. 点击“立即生成 Word”。
6. 等待运行完成，在右侧“报告输出”中点击“下载”。

结果会同时保存在本机 `E:\tt\outbox` 文件夹中。

### 2. 创建每天自动发送的订阅

1. 在工作台输入带时间的需求，例如：

   ```text
   最近3个月上海服务器招标信息，每天9:00发送给我
   ```

2. 选择“创建订阅”。
3. 勾选“同时发送飞书”。
4. 提交后，打开顶部“订阅管理”查看是否启用。

系统以后只发送新增内容，不会每天重复发送同一批公告。

### 3. 查看和跟进项目

1. 打开顶部“机会情报”。
2. 点击感兴趣的项目。
3. 查看项目评分、原始公告、截止时间、风险和下一步建议。
4. 需要团队跟进时，把项目发送到飞书。

发送后可以在飞书中看到项目卡片，并可建立负责人任务和截止日程。任务状态会定时同步回 TenderTrace 和多维表格。

### 4. 在飞书群里使用机器人

进入飞书的 `TT 项目组群`。直接发送消息即可；在消息较多时也可以先输入 `@123`。

常用示例：

```text
最近1个月上海服务器招标信息都有哪些？
```

```text
记录组织记忆 本周重点跟进上海服务器项目
```

```text
查询组织记忆 上海服务器
```

```text
项目意见 pbc_procurement:04b40d52-b636-11f1-88d4-b4055dfb2cc6：建议本周联系客户确认预算
```

其中机会编号直接从飞书项目卡片中复制即可。

机器人会在群里回复。查询类问题可以生成报告或订阅；组织记忆会保存到 TenderTrace 的“组织协作”页面。

### 5. 查看飞书多维表格

打开飞书中的“招标机会”多维表格，可以查看：

- 项目名称和来源；
- 机会评分和阶段；
- 负责人和任务状态；
- 截止日期和日程；
- Word 报告和最近同步时间。

人工填写的跟进状态不会因为普通报告同步而被随意覆盖。

## 四、顶部菜单怎么理解

| 菜单 | 什么时候使用 |
|---|---|
| 工作台 | 新查询、生成 Word、创建订阅 |
| 机会情报 | 查看和筛选值得跟进的项目 |
| 历史运行 | 查找以前运行过的任务和结果 |
| 订阅管理 | 查看、手动运行或删除定时订阅 |
| 数据源 | 检查招标网站是否正常 |
| Agent评测 | 查看系统检索和处理能力的技术指标 |
| 用户记忆 | 查看系统积累的使用建议和周报 |
| 组织协作 | 查看团队成员、共享文件和组织记忆 |
| 设置 | 查看飞书、模型及其他连接状态 |

## 五、出现问题时怎么办

### 网页打不开

1. 双击 `E:\tt\scripts\start-local.cmd`。
2. 等待 10 秒后刷新网页。
3. 仍打不开时，先双击 `stop-local.cmd`，再双击 `start-local.cmd`。

### 飞书机器人不回复

1. 确认消息发在 `TT 项目组群`。
2. 确认本机没有关机，TenderTrace 已启动。
3. 可以在消息前加 `@123` 再试一次。
4. 双击 `E:\tt\scripts\feishu-audit.cmd` 查看连接检查结果。

### 没收到飞书报告

1. 创建查询或订阅时确认勾选“同时发送飞书”。
2. 在“设置”中确认飞书消息、项目群和长连接显示可用。
3. 在“报告输出”中找到报告，点击“发送飞书”重试。

### 某个数据源没有结果

打开“数据源”页面查看状态。某个网站暂时失败时，其他正常数据源仍可继续提供结果。

## 六、使用时记住三点

1. 机器人依赖这台电脑上的 TenderTrace 服务；电脑关机或服务停止时，机器人暂时不会处理新命令。
2. 机器人自然语言入口使用 `TT 项目组群`；`123` 的单聊目前不作为正式入口。
3. `.env.local` 和 `secrets` 文件夹中有连接凭据，不要发给别人，也不要上传到公开网站。

## 七、推荐的日常用法

每天只需要做三件事：

1. 在“工作台”提出新的招标查询。
2. 在“机会情报”里挑选值得跟进的项目并发送到飞书。
3. 在 `TT 项目组群` 查看提醒、领取任务和补充团队意见。

已有的“上海服务器”订阅会每天 09:00 自动检查新增公告并发送到项目群。
