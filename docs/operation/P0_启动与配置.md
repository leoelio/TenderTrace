# P0 启动与配置

## 目标

P0 只验证工程底座，不实现真实抓取。验收口径是：配置可读、数据库可初始化、健康接口可启动、`sent_history` 能阻止同一订阅重复发送同一项目簇。

## 安装

```powershell
python -m venv .venv
.\\.venv\\Scripts\\python -m pip install -e .[dev]
copy .env.example .env.local
```

## 配置

`.env.local` 是本地私有文件，已被 `.gitignore` 忽略。不要把账号、密码、OpenAI Key、千里马登录态写入代码或提交仓库。

模型模式：

- `TENDERTRACE_MODEL_MODE=local`：默认，使用 Ollama。
- `TENDERTRACE_MODEL_MODE=cloud`：使用 OpenAI 兼容接口，要求 `OPENAI_API_KEY` 存在。
- `TENDERTRACE_MODEL_MODE=disabled`：完全禁用模型增强，只走规则逻辑。

本地模型推荐先用 `qwen3:8b`，兼顾中文理解和普通开发机可运行性。更强机器后续可切 `qwen3:14b` 或更大模型。

## 命令

```powershell
.\\.venv\\Scripts\\python -m tendertrace init-db
.\\.venv\\Scripts\\python -m tendertrace config-check
.\\.venv\\Scripts\\python -m tendertrace health
.\\.venv\\Scripts\\python -m tendertrace serve
```

健康接口：

```text
http://127.0.0.1:8000/api/health
```

outbox 查询接口：

```text
http://127.0.0.1:8000/api/outbox
```

## P0 验收

```powershell
.\\.venv\\Scripts\\python -m unittest discover -s tests
```

通过后应确认：

- `data/tendertrace.sqlite3` 已创建。
- 数据库包含 `subscriptions`、`runs`、`notices`、`clusters`、`sent_history`、`trace_events`、`outbox_messages` 等核心表。
- `config-check` 只输出 `openai_key_configured: true/false`，不会输出密钥值。
- `sent_history` 对 `(subscription_id, cluster_key)` 有唯一约束，重复写入会被拒绝。
