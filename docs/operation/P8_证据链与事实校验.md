# P8 证据链与事实校验

## 阶段目标

P8 的目标是在 P7 清洗去重之后，为每条进入报告的招投标公告生成可追溯证据：

- 记录详情正文的 `snapshot_sha256`。
- 生成证据摘录，便于人工回到原文核对。
- 规范化附件链接，识别 PDF、Word、Excel、压缩包等附件类型。
- 对标题、详情正文、核心内容、来源链接做规则化事实校验。
- 将证据写入 `evidence_items` 表，并同步保存在 `notices.fields_json`。
- 在 Word 报告中展示事实校验状态、证据哈希和证据摘录。

## 成功标准

1. TenderGraph 运行节点变为 `intent -> collect -> evidence -> report`。
2. `runs.stats_json` 包含 `evidence_checked`、`evidence_passed`、`evidence_warnings`。
3. `notices.snapshot_sha256` 有值。
4. `evidence_items` 表有对应证据记录。
5. Word 逐条详情包含 `事实校验`、`证据哈希`、`证据摘录`。
6. 全量单元测试通过，Ruff 通过。

## 核心文件

- `tendertrace/pipeline/evidence.py`：证据链、附件规范化、事实校验。
- `tendertrace/runner.py`：新增 `evidence` 节点，控制持久化与增量过滤顺序。
- `tendertrace/db.py`：新增 `evidence_items` 表。
- `tendertrace/report/docx_writer.py`：Word 报告展示证据字段。
- `tests/test_pipeline_evidence.py`：证据模块单元测试。
- `tests/test_runner.py`：状态图节点、证据入库测试。
- `tests/test_report_writer.py`：Word 证据展示测试。

## 执行顺序

P8 后的单次运行顺序如下：

```text
intent
  -> collect
  -> evidence
  -> report
```

关键点是：先完成跨来源去重，再做证据校验和持久化，最后才做订阅增量过滤。

这样做的原因是：

- `sent_history` 必须基于 P7 的 `cluster_key` 判断是否已推送。
- 已推送内容不应重复进入 Word。
- 但本轮采集到的候选公告仍应入库，便于追踪来源状态和证据质量。

## 数据表变化

新增表：

```sql
CREATE TABLE IF NOT EXISTS evidence_items (
    id TEXT PRIMARY KEY,
    notice_id TEXT NOT NULL,
    cluster_key TEXT NOT NULL,
    source_site TEXT NOT NULL,
    source_url TEXT NOT NULL,
    snapshot_sha256 TEXT NOT NULL,
    excerpt TEXT NOT NULL,
    attachments_json TEXT NOT NULL DEFAULT '[]',
    fact_checks_json TEXT NOT NULL DEFAULT '[]',
    quality_score REAL NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL DEFAULT (datetime('now'))
)
```

`notices` 表已有的 `snapshot_sha256` 字段现在会写入详情正文证据哈希。

## 验收观察点

运行一次真实查询后，可以检查：

```powershell
python -m tendertrace run-once "最近10天全国设备招标信息都有哪些" --max-pages 1 --max-results 4
```

然后检查：

- `outputs/` 下是否生成 Word。
- `outbox/` 下是否有同名可下载文件。
- Word 详情区是否有事实校验和证据摘录。
- SQLite 中 `evidence_items` 是否有记录。
- 运行详情中的 stats 是否包含证据统计。

## 当前限制

- P8 的事实校验是规则型校验，不调用 LLM 判断事实真假。
- 证据来源优先使用适配器已经抽取到的详情正文和附件链接。
- 如果来源站点详情正文抓取失败，系统会给出 `warning`，不会伪造内容。
- PDF 正文解析尚未展开到文件下载与全文解析；本阶段先完成附件链接识别、入库和报告展示。
