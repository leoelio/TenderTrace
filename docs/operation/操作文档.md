# TenderTrace 操作文档

## 1. 环境要求

- Windows 10/11 或同等 Python 运行环境。
- Python 3.11+。
- 网络可访问目标招投标网站。
- 如需登录站：本机可打开 Playwright 浏览器。
- 如需本地模型：安装 Ollama。
- 如需云端模型：在 `.env.local` 配置 `OPENAI_API_KEY`。

## 2. 安装

```powershell
cd D:\超聚变
python -m venv .venv
.\.venv\Scripts\python -m pip install -e .[dev]
```

如果使用系统 Python，也可以直接运行：

```powershell
python -m pip install -e .[dev]
```

## 3. 配置

复制模板：

```powershell
copy .env.example .env.local
```

`.env.local` 是本地私密配置，已被 `.gitignore` 忽略。

### 3.1 默认路径

```env
TENDERTRACE_DB_PATH=data/tendertrace.sqlite3
TENDERTRACE_OUTPUTS_DIR=outputs
TENDERTRACE_OUTBOX_DIR=outbox
TENDERTRACE_SNAPSHOTS_DIR=snapshots
TENDERTRACE_SECRETS_DIR=secrets
```

### 3.2 云端模型

```env
TENDERTRACE_MODEL_MODE=cloud
TENDERTRACE_MODEL_ENHANCEMENT_ENABLED=true
TENDERTRACE_MODEL_REQUEST_TIMEOUT=30
OPENAI_API_KEY=填入你的key
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-5.5
TENDERTRACE_OPENAI_API_STYLE=responses
```

### 3.3 本地模型

本地模型使用 Ollama：

```env
TENDERTRACE_MODEL_MODE=local
TENDERTRACE_MODEL_ENHANCEMENT_ENABLED=true
TENDERTRACE_OLLAMA_BASE_URL=http://127.0.0.1:11434
TENDERTRACE_OLLAMA_MODEL=qwen3:8b
```

先在终端验证：

```powershell
ollama run qwen3:8b
```

### 3.4 不使用模型

```env
TENDERTRACE_MODEL_MODE=disabled
TENDERTRACE_MODEL_ENHANCEMENT_ENABLED=false
```

规则解析、采集、报告仍可运行。

### 3.5 邮件投递

默认只启用 Web 下载和本地 outbox：

```env
TENDERTRACE_DELIVERY_CHANNELS=web,outbox
```

如需把生成后的 Word 作为附件发送邮件，在 `.env.local` 中增加：

```env
TENDERTRACE_DELIVERY_CHANNELS=web,outbox,email
TENDERTRACE_SMTP_HOST=smtp.example.com
TENDERTRACE_SMTP_PORT=587
TENDERTRACE_SMTP_USERNAME=你的SMTP账号
TENDERTRACE_SMTP_PASSWORD=你的SMTP授权码
TENDERTRACE_SMTP_FROM=sender@example.com
TENDERTRACE_SMTP_TO=receiver@example.com
TENDERTRACE_SMTP_USE_TLS=true
```

`config-check` 只显示 `smtp_password_configured`，不会输出 SMTP 密码。

### 3.6 飞书多维表格台账

如需把每次新增公告同步到飞书多维表格，在 `.env.local` 中增加：

```env
TENDERTRACE_DELIVERY_CHANNELS=web,outbox,feishu_bitable
TENDERTRACE_FEISHU_APP_ID=cli_xxx
TENDERTRACE_FEISHU_APP_SECRET=仅放本地
TENDERTRACE_FEISHU_BITABLE_APP_TOKEN=base_xxx
TENDERTRACE_FEISHU_BITABLE_TABLE_ID=tbl_xxx
TENDERTRACE_PUBLIC_BASE_URL=http://127.0.0.1:8000
```

检查连接与字段：

```powershell
python -m tendertrace feishu-bitable-check
python -m tendertrace feishu-bitable-check --ensure-fields
```

运行完成后，TT 会按 `项目指纹` 去重：飞书表中没有的项目新增为 `状态=新增`；已经存在的项目只更新 `Word 报告`、`运行ID` 和 `最近同步时间`，不覆盖人工维护的状态。

## 4. 初始化

```powershell
python -m tendertrace init-db
python -m tendertrace config-check
python -m tendertrace feishu-bitable-check
python -m tendertrace model-status
python -m tendertrace model-doctor
python -m tendertrace source-status
python -m tendertrace verify-qianlima
python -m tendertrace demo-check
```

`config-check` 不会输出 API key，只显示 `openai_key_configured`。
`model-doctor` 默认不联网；需要真实调用当前模型时再运行 `python -m tendertrace model-doctor --live`。
`demo-check` 用于录屏前审计当前工作区是否具备多问题、Word/outbox、trace、订阅增量和模型/来源状态证据。

## 5. 启动 Web

```powershell
python -m tendertrace serve
```

默认地址：

```text
http://127.0.0.1:8000/
```

如果端口占用：

```powershell
$env:TENDERTRACE_PORT='8001'
python -m tendertrace serve
```

## 6. 立即运行

CLI：

```powershell
python -m tendertrace run-once "最近7天全国服务器招标信息都有哪些" --max-pages 1 --max-results 4
```

Web：

1. 打开工作台。
2. 在文本框输入自然语言问题。
3. 设置翻页数和结果数。
4. 点击运行采集。
5. 在 Outbox 下载 Word。
6. 点击追踪查看事件流。

## 7. 创建订阅

CLI：

```powershell
python -m tendertrace create-subscription "最近3个月上海充电桩招标信息都有哪些，请汇总后每天9:00发送给我" --max-pages 1 --max-results 5
```

查看订阅：

```powershell
python -m tendertrace list-subscriptions
```

手动触发：

```powershell
python -m tendertrace run-subscription <subscription_id>
```

订阅触发后，`sent_history` 会记录已经推送过的项目簇。下一次同一订阅只输出新增内容。

Web 的“订阅管理”页会展示最近一次运行的新增条数、跳过历史条数、下次触发时间、最近 Word 下载入口和邮件状态，适合录屏时证明订阅是增量推送而不是重复生成。

快速演示“定时订阅 + 增量不重复”：

```powershell
python -m tendertrace demo-incremental "最近3个月上海充电桩招标信息都有哪些，请汇总后每天9:00发送给我" --max-pages 1 --max-results 5
```

该命令会创建一个订阅并连续触发两次运行。第一次 Word 包含新增公告；第二次复用同一订阅的 `sent_history`，已推送项目簇会进入 `second_skipped_sent`，第二份 Word 只保留新增内容。

## 8. 登录千里马

```powershell
python -m tendertrace login-qianlima
python -m tendertrace verify-qianlima
```

步骤：

1. 程序打开可见浏览器。
2. 用户手动登录免费会员账号。
3. 登录完成后回到终端按 Enter。
4. 系统保存 Playwright `storage_state` 到 `secrets/qianlima_storage_state.json`。

系统不会保存账号密码。

检查状态：

```powershell
python -m tendertrace source-status
python -m tendertrace verify-qianlima
```

Web 的“数据源”页会展示公开源和千里马的入口路由、发现规则、近次运行、累计命中、成功率、阻断、重试和页面快照数。若千里马登录态失效，状态会显示 `login_required`，公开源仍可继续运行。

## 13. 常见问题

### 13.1 cloud model mode requires OPENAI_API_KEY

说明 `.env.local` 或环境变量里没有可读取的 `OPENAI_API_KEY`。填写后重新运行 `model-status`。

### 13.2 OpenAI 请求超时

将：

```env
TENDERTRACE_MODEL_REQUEST_TIMEOUT=30
```

模型失败不会中断主流程，系统会降级使用规则 BidQL。

### 13.3 千里马显示 login_required

执行：

```powershell
python -m tendertrace login-qianlima
python -m tendertrace verify-qianlima
```

### 13.4 附件解析为 0

可能原因：

- 当前公告没有附件。
- 附件是 ZIP、RAR、DOC、XLS 等暂不支持格式。
- 附件下载超时或超过大小阈值。

### 13.5 Web 启动失败

检查端口是否占用，或切换端口：

```powershell
$env:TENDERTRACE_PORT='8001'
python -m tendertrace serve
```
