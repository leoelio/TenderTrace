# P11 交付文档与验收包

## 阶段目标

P11 不新增采集能力，而是补齐赛题交付材料和验收支撑：

- 生成赛题要求命名的 `详设文档.md`。
- 生成统一 `操作文档.md`。
- 生成 Demo 视频录制脚本。
- 更新 README 到当前 P11 状态。
- 增加交付文档测试，防止关键文档缺失或泄露 API key。

## 成功标准

1. `docs/design/详设文档.md` 存在，覆盖核心模块和创新点。
2. `docs/operation/操作文档.md` 存在，覆盖安装、配置、运行、验证、订阅、登录态和常见问题。
3. `docs/demo/Demo演示脚本.md` 存在，覆盖输入到输出的完整录屏流程和多个问题。
4. README 当前阶段、测试数量和模型能力与代码状态一致。
5. 测试能检查交付文档存在且不包含真实 key 模式。

## 交付物映射

| 赛题交付要求 | 当前文件 |
|---|---|
| 工具执行后的 Word 文件 | `outputs/`、`outbox/` |
| 设计文档 | `docs/design/详设文档.md` |
| 代码文件 | `tendertrace/`、`web/`、`tests/` |
| 操作文档 | `docs/operation/操作文档.md` |
| Demo 视频 | `docs/demo/Demo演示脚本.md` 支撑录制 |

## 验证命令

```powershell
python -m unittest tests.test_delivery_docs -v
python -m unittest discover -s tests -v
python -m ruff check .
```

## 注意事项

- `.env.local` 不作为交付文档内容展示。
- 文档可以提 `OPENAI_API_KEY` 这个变量名，但不能包含真实 key。
- Demo 录制时不要打开 `.env.local` 明文。
