# 低频能力收纳与大屏退出验收报告

验收日期：2026-09-29  
验收结论：**通过**

## 提升目标

降低低频功能对日常操作的干扰，并解决进入大屏后不容易返回的问题。

## 实现结果

- 投标项目页将同步任务、推送公告变更、发送经营晨报和打开飞书台账收纳到“更多操作”。
- 品类、等级和排序筛选独立成清晰的筛选栏。
- 团队协作页的企业投标记忆图谱默认收起，标注为“历史项目与经验”，需要时再展开。
- 大屏模式左上角固定显示“退出大屏”按钮，并保留 Esc 快捷退出。
- 动效和大屏入口移入“更多 > 显示”，降低顶部工具密度。

## 验收证据

- 浏览器实际进入大屏，固定退出按钮可见。
- 点击退出按钮后 `presentation-mode` 状态被清除，页面恢复普通模式。
- 浏览器可正常打开“更多操作”和历史项目折叠区。
- 原同步、推送、晨报、记忆图谱控件 ID 均保留，现有事件绑定不变。

## 回归影响检查

- 大屏模式仍适用于首页、雷达、战情图和项目详情。
- Esc 原有退出方式继续有效。
- 低频操作仅改变可见层级，没有删除接口或按钮。

结论：低频能力按需展示，大屏具备稳定、明显的退出路径。
