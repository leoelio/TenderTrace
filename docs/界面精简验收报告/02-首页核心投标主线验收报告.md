# 首页核心投标主线验收报告

验收日期：2026-09-29  
验收结论：**通过**

## 提升目标

把首页从比赛功能陈列页调整为可直接工作的招投标首页，让用户按“查找—管理—协作”完成主要任务。

## 实现结果

- 主标题改为“从查项目到交标书，一条线完成”。
- 首页提供直接搜索框及三个常用搜索示例。
- 三个核心步骤分别进入查招标、投标项目和团队协作。
- 重点投标项目保留机会价值、企业匹配度、投标准备度、证据和待办信息。
- 系统状态与数据概览改为默认收起，减少首页噪音。
- 删除首页上的四层架构、七分钟演示路线和数据源边界陈列；对应业务模块仍保留在“更多”。

## 验收证据

- 浏览器截图检查：首页在 1440×1000 视口内完整展示核心流程，没有横向溢出。
- 首页搜索会进入查招标工作台，并继续触发现有意图解析。
- “继续准备标书”继续打开原有投标项目详情。
- 首页状态刷新仍读取机会雷达、演示可靠性和飞书概览接口。
- Node 前端合同测试及 Python 全量回归测试通过。

## 回归影响检查

- 原有机会统计、案例评分、证据和行动数据节点保留。
- 首页不再请求未使用的团队训练概览，减少一次无效请求。
- 数据源、训练、评测和演示控制台仍可从“更多”进入。

结论：首页主线清楚，原投标数据和跳转能力未受损。
